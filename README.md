# MA3_MACROS


HOW IT WORKS: 1-TOUCH SEQUENCE & FUNCTION ASSIGNMENT

The Operator Experience (Your 3 Steps)

Step 1: Tap any sequence in your Sequences Pool (it receives the yellow selection border).

Step 2: Tap the Macro for the function you want (e.g., ASSIGN TOGGLE or ASSIGN FLASH).

Step 3: Press the Playback Button on your console or screen.


That sequence is assigned to that playback and configured with that function with only one physical press on the playback.
